## 1. 문제 정의

| 항목 | 내용 |
|---|---|
| 대회 | 제3회 풍력발전량 예측 AI 경진대회 BARAM 2026 (Dacon · KPX) · 2026.07–08 · 1인 |
| 대상 | 태백 가덕산 풍력단지 3개 KPX 그룹 |
| 입력 | LDAPS 16격자 + GFS 9격자 day-ahead 예보, 학습기간 SCADA |
| 출력 | 2025년 8,760시간 × 3그룹 발전량(kWh) — D-1 13:00 발표 예보로 D일 24시간 예측 |
| 학습 | 2022–2024 라벨 26,304행 (g3는 2년치) |
| 제약 | 자기회귀 불가 · 예측기준시점 이후 정보 금지 · 재분석자료 금지 · 외부데이터는 공개·재현 가능해야 함 |

### 평가 지표
```
Score = 0.5·(1 − NMAE) + 0.5·FICR          (실측 ≥ 설비용량 10% 시각만 채점)
FICR  = Σ 실측·price(e) / (4·Σ 실측),      e = |예측−실측| / 설비용량
price(e) = 4 (e ≤ 6%) / 3 (e ≤ 8%) / 0
```
- FICR = **KPX 정산금 산식** 그대로. 오차 8% 안이면 돈, 밖이면 0 → 계단형 손실
- price(e) = 3·1{e≤8%} + 1·1{e≤6%} → **±8% 창이 지배**, 실측 가중이라 **고출력 시각이 결정적**
- 평균오차 줄이기 ≠ 밴드 안에 들어가기 → 후반 의사결정 대부분이 여기서 나옴

## 3. 접근

### 3-1. 파이프라인
```
LDAPS 16격자 + GFS 9격자 + ECMWF IFS(직접 수집)
   → 103 피처 (풍속·풍향 sin/cos·공기밀도·ws³·시어·인접시각 램프·공간 산포)
   → LightGBM ┐
     MLP      ├ 등가중 평균 ─┐
     SeqCNN   ┘             ├→ α·pred → floor → clip → 조건부 보정
     EC-only LightGBM (w) ──┘
```
| 구성 | 내용 |
|---|---|
| 타깃 / 가중 | CF = kWh/설비용량 · 샘플가중 clip(0.5+1.5·CF, 0.5, 2) — 채점 필터 반영 |
| LightGBM | objective l1 · num_leaves 63 · lr 0.04 · 1500 trees · 시드 3 |
| MLP | [256,128,64] · BN·Dropout 0.2 · 가중 L1 · 시드 3 |
| SeqCNN | 24h 예보블록 · dilated Conv1d 1·2·4 · 가중 L1 · 시드 3 |
| ECMWF 멤버 | EC 전용 52피처 LightGBM · w = 0.15/0.15/0.12 · 잔차상관 0.91 → 0.77–0.84 (유일한 다양성 원천) |
| 그룹별 피처 | g1 102 / g2 GBM 148 · NN 112 / g3 112 — 같은 데이터도 어느 멤버에 주느냐로 부호가 갈림 |
| 후처리 | α 1.06/1.04/1.01 · floor 0.18C — LOYO OOF에서 총점 최적 |
| 조건부 보정 | g3 정지(Q1 ×0.88, Q2 ×0.95) · g3 고풍속(≥학습 상위 30% & 4–12월 ×1.06) · 계절 |

### 3-2. 검증 프로토콜
로컬 CV ↔ 리더보드 **부호 반전 8건** (2025 고풍속 OOD · g3 라벨 2년 · 후처리-모델 강결합) → 규칙화

| 규칙 | 근거 |
|---|---|
| matched-pair만 신뢰 (실물 base + 변경 1개, 후처리 고정, LOYO) | 정보 추가 레버 3전 3승, 전이율 74–98% |
| 채택 문턱: 3그룹환산 ≥ +0.0012 AND 고풍속(상위 30%) ≥ 0 | LB 역산 음성 오프셋 −0.0008 |
| GBM만으로 거르지 않음 (3멤버 재학습) | GBM-only 스크린 부호 반전 8건 |
| nested 선택 · 사전 등록 판정 · 사후 선택 금지 | Public/Private 상관 −0.9999 |
| "모델 동역학 변경"은 CV로 판정 불가 → 정보 추가에 집중 | LB 0-3, in-distribution CV가 OOD 외삽을 못 잼 |

### 3-3. 가장 큰 도약 — 데이터 안의 사실
- SCADA를 상태기계(정지 = 풍속>4 m/s & 출력≈0 / 가동 = 출력>5%)로 읽음 → **g3 5기 중 1기가 2024-12-02부터 학습 종료까지 완전 정지**, 학습행 33%가 부분 정지
- 2025 상반기 정지 지속 가정 → **Q1 ×0.88 / Q2 ×0.95** 계단 보정 → **+0.0067** (다른 레버의 10배)
- 제출 3개 동시 업로드로 분기별 기여 분해: Q1 +0.0046 / Q2 +0.0005 / H2 −0.0009 → 창 확정
- 정지 오염이 고풍속 라벨을 4/5로 눌러 **과소예측 학습** → 독립 실험 3건이 모두 g3 고풍속대 지목 → **허브풍속 상위 30% 시각만 ×1.06** → +0.0012
- 라벨 복원 재학습(근원 치료)은 폴드 충돌로 기각 → **작고 · 양 폴드 검증 · 좁은 게이트** 개입만 전이됨

### 3-4. 실측으로 닫은 가설
| 가설 | 실험 | 결과 |
|---|---|---|
| NMAE를 팔아 FICR을 사면 총점이 오른다 | 학습손실 pinball-τ · 밴드최적 결정규칙 · (α,β,floor) 공동탐색 · 선택목적 κ | 전 층에서 **교환비 1:1** — α/floor가 이미 총점 최적이라 한계교환비 1:1 |
| 불확실성 정보를 피처로 주면 오른다 | 앙상블 스프레드 · 예보 개정폭(D-3런 직접 수집) · 저풍속 노출 등 5종 | 진단 신호 뚜렷(밴드 획득률 1.6배)하나 **점수 0** — 분산은 중앙값을 안 바꿈 |
| 알고리즘을 섞으면 다양성이 생긴다 | CatBoost / XGBoost / ExtraTrees, 63개 조합 전수 | 잔차상관 0.95–0.97 → **다양성 ≈ 0**, 입력 정보원 분리만 유효 |

## 5. 배운 것
- **지표를 먼저 분해하라** — FICR = 3·1{e≤8%} + 1·1{e≤6%} 한 줄이 후처리·검증·레버 선택을 바꿨다
- **가장 큰 이득은 모델 밖에** — 터빈 정지는 CV로 못 찾는다. 데이터를 읽고, 대조군으로 검증하고, LB 프로브로 창을 잡았다
- **검증 프로토콜은 실패를 먹고 자란다** — 부호 반전 8건 → 규칙 5개 → 정보 추가 3전 3승 → Public 49위 → Private 18위
- **공개 LB는 계측기지 목표가 아니다** — 노이즈(σ 0.0006–0.0009)를 먼저 재고 그 위에서만 판정
- **점수보다 규정** — 위반은 수집 단계가 아니라 최종 피처에 들어간 값 기준으로 검사
